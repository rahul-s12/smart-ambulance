# References

This folder holds external material supporting the design and implementation: sensor and board datasheets, protocol documentation, research references, and dataset source information.

## Responsibilities

- Keep source information for hardware wiring, measurement characteristics, and software/protocol choices.
- Preserve links, titles, publishers/authors, relevant versions, and access dates where useful.
- Record dataset origins, licensing, limitations, and preparation information before ML work begins.
- Support design explanations in `../docs/` without duplicating the team's requirements here.

## How to use this folder

1. Add reference files or a source-list document directly in this existing folder as needed; do not create additional folders yet.
2. Prefer official datasheets and primary protocol documentation for implementation decisions.
3. Give each entry enough source information for another contributor to locate the original material.
4. Record which component or decision uses the reference and link it from the relevant documentation.
5. Check redistribution permissions before committing copies. Use a citation and source link when a copy should not be included.
6. Keep large datasets, credentials, and patient records out of Git; document the source and preparation steps instead.

## Current state

No supporting reference material has been collected here yet. `.gitkeep` preserves the planned location.
